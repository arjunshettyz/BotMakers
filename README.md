# BotLeague Frontend

A frontend-only React + TypeScript + Tailwind CSS landing page for BotLeague, a robotics competition arena concept.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Features

- Full-screen hero with BotLeague branding
- Event, journey, category, and discipline sections
- Responsive dark UI with custom visuals
- Frontend-only implementation with no backend

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
